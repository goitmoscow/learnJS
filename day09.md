## Разминка

У массива товаров нужно получить названия доступных товаров. Как изменится форма данных после filter и после map?

## 1. Составная задача

Сначала сформулируйте каждое преобразование отдельно. Например: выбрать товары, получить названия, собрать строку.

Сохраните промежуточные данные в переменные и проверьте их до объединения шагов.

```javascript
const items = [
  { name: "Чай", available: true },
  { name: "Кофе", available: false }
];
const selected = items.filter((x) => x.available);
const names = selected.map((x) => x.name);
console.log(names.join(", "));
```

Ожидаемый вывод:

```text
Чай
```

## 2. Контракт функции

Уточните, гарантированы ли корректные входные данные. В учебной задаче можно опираться на явно указанное условие.

Если требуется проверка данных, договоритесь о результате ошибки. Проверка типа не должна заменять смысловые ограничения.

```javascript
function addNumbers(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    return "Некорректные данные";
  }
  return a + b;
}
console.log(addNumbers("2", 3));
```

Ожидаемый вывод:

```text
Некорректные данные
```

## 3. Пустой результат

Пустой массив часто является корректным результатом отбора. Для итогового текста может понадобиться отдельное сообщение.

Проверяйте условие до построения итогового ответа, если формат пустого результата отличается.

```javascript
const names = [];
if (names.length === 0) {
  console.log("Нет участников");
} else {
  console.log(names.join(", "));
}
```

Ожидаемый вывод:

```text
Нет участников
```

## 4. Проверка исходных данных

Перед преобразованием вспомните, какие операции меняют массив или объект.

sort меняет массив. Если нужна независимая сортировка, можно сначала сделать slice(), а затем sort с числовым компаратором.

```javascript
const original = [10, 2, 30];
const sorted = original.slice().sort((a, b) => a - b);
console.log(original.join(", "));
console.log(sorted.join(", "));
```

Ожидаемый вывод:

```text
10, 2, 30
2, 10, 30
```

### Задача 1. Стоимость заказа

Каждый объект заказа содержит конечные неотрицательные числа price и quantity. Верните сумму price * quantity по всем позициям.

Имя функции: orderTotal.

Примеры:

- [{price: 100, quantity: 2}, {price: 50, quantity: 1}]: 250
- []: 0

### Задача 2. Товары в бюджете

Верните названия товаров с price <= budget, сохранив порядок. Входные объекты содержат name и числовое price.

Имя функции: affordableNames.

Примеры:

- [{name: 'Чай', price: 100}, {name: 'Кофе', price: 200}], 100: ['Чай']
- []: []

### Задача 3. Отчёт об участниках

Дан корректный массив объектов name и age. Выберите людей старше cutoffAge, приведите имена к верхнему регистру и верните текст 'ИМЯ (возраст)' через запятую. При отсутствии совпадений верните 'Нет участников'.

Имя функции: formatPeople.

Примеры:

- [{name: 'Анна', age: 25}], 20: 'АННА (25)'
- [], 20: 'Нет участников'

### Задача 4. Длины слов

Получите массив длин непустых слов строки. Разделитель обычный пробел, повторяющиеся пробелы допускаются. Слова без emoji.

Имя функции: wordLengths.

Примеры:

- 'кот и собака': [3, 1, 6]

### ★ 1. Сортировка без изменения входа

Напишите sortedReadings(numbers) через toSorted с числовым компаратором. [12, 3, 21] → [3, 12, 21]; [-4, 0, -9] → [-9, -4, 0]; [] → []. Проверьте неизменность входа, затем предложите аналог через slice().sort().

Что исследовать: Найдите отличие sort и toSorted, а также порядок сортировки без компаратора. Объясните, почему сортировка чисел как строк даёт другой результат.

Статьи: [Array.toSorted](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/toSorted).

### ★ 2. Принять только корректные показания

Напишите validReadings(values), возвращающую новый массив только конечных значений типа number. [0, "7", NaN, Infinity, -3, null] → [0, -3]; [] → []. Объясните, почему filter(Boolean) и проверка одного typeof дают неверный результат.

Что исследовать: Найдите различия Number.isFinite и глобальной isFinite. Сформулируйте контракт без неявного преобразования строк.
