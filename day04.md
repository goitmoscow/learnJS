# День 4. Массивы, изменение и копирование

## Результат занятия

- Прочитать и изменить элементы массива
- Выбрать способ обхода массива
- Отличить исходный массив от копии

Что уже нужно знать: Циклы, индексы, функции и накопитель.

## Разминка

Для [10, 20, 30] назовите length, первый и последний индексы. Что будет при чтении индекса 3?

## 1. Элементы и length

Массив хранит значения по индексам. Запись по индексу меняет соответствующий элемент.

const запрещает переназначить переменную, но не запрещает менять содержимое массива.

```javascript
const names = ["Анна", "Олег"];
names[1] = "Ира";
console.log(names[0]);
console.log(names[1]);
console.log(names.length);
```

Ожидаемый вывод:

```text
Анна
Ира
2
```

## 2. Добавление и удаление

push добавляет в конец, pop извлекает последний элемент. shift и unshift делают похожее в начале.

Эти методы меняют исходный массив. push возвращает новую длину, pop возвращает удалённый элемент.

```javascript
const queue = ["Анна"];
console.log(queue.push("Олег"));
console.log(queue.pop());
console.log(queue.length);
```

Ожидаемый вывод:

```text
2
Олег
1
```

## 3. Обход for…of

for…of получает значения массива по очереди. Используйте его, если индекс не нужен.

Обычный for удобен, когда нужен индекс. for…in перебирает свойства и не является основным способом обхода массива.

```javascript
const prices = [10, 20, 5];
let total = 0;
for (const price of prices) {
  total += price;
}
console.log(total);
```

Ожидаемый вывод:

```text
35
```

## 4. Копия через slice

slice возвращает новый массив. Начальная граница включается, конечная не включается.

slice() без аргументов создаёт поверхностную копию. Вложенные объекты остаются общими ссылками.

```javascript
const original = [10, 20, 30];
const copy = original.slice();
copy.push(40);
console.log(original.length);
console.log(copy.length);
console.log(original.slice(1, 2)[0]);
```

Ожидаемый вывод:

```text
3
4
20
```

## 5. Изменение через splice

splice меняет исходный массив. Параметры: откуда начать, сколько удалить, что вставить.

Метод возвращает массив удалённых элементов. slice и splice решают разные задачи.

```javascript
const letters = ["а", "б", "в"];
const removed = letters.splice(1, 1, "я");
console.log(removed[0]);
console.log(letters[1]);
console.log(letters.length);
```

Ожидаемый вывод:

```text
б
я
3
```

## 6. Поиск циклом

Начните с решения, шаги которого можете объяснить. Сохраните значение или верните его при первом совпадении.

Заранее договоритесь, какой результат означает «не найдено». Например, индекс -1.

```javascript
function findIndexOf(numbers, target) {
  for (let i = 0; i < numbers.length; i += 1) {
    if (numbers[i] === target) return i;
  }
  return -1;
}
console.log(findIndexOf([4, 8], 8));
```

Ожидаемый вывод:

```text
1
```

## 7. Одна ссылка и новый массив

Присваивание массива другой переменной не создаёт новый массив: обе переменные указывают на тот же объект. Это видно и через ===, и через изменения. Array.isArray отличает массив от обычного объекта.

Обход от length - 1 до 0 подходит для построения нового списка в обратном порядке. Новый список создаётся отдельно; исходный не меняется. В пустом массиве начальный индекс -1, поэтому цикл сразу заканчивается.

```javascript
const source = [6, 9, 12];
const alias = source;
console.log(source === alias);
alias.push(15);
console.log(source.length);
const backwards = [];
for (let i = source.length - 1; i >= 0; i -= 1) {
  backwards.push(source[i]);
}
console.log(backwards.join(","));
console.log(source.join(","));
console.log(Array.isArray(source));
```

Ожидаемый вывод:

```text
true
4
15,12,9,6
6,9,12,15
true
```

### Задача 1. Последний элемент

Верните последний элемент массива. Для пустого массива верните undefined.

Имя функции: lastItem.

Примеры:

- [4, 8]: 8
- []: undefined

### Задача 2. Дополнить копию

Верните новый массив с item в конце. Исходный массив менять нельзя. Решите через slice и push.

Имя функции: appendCopy.

Примеры:

- [1, 2], 3: [1, 2, 3]
- Исходный список остаётся [1, 2]

### Задача 3. Количество выше порога

Верните количество чисел, строго превышающих limit. Используйте for…of.

Имя функции: countAbove.

Примеры:

- [10, 20, 30], 20: 1
- [], 0: 0

### Задача 4. Удаление в копии

Дан массив и корректный индекс. Верните новый массив без элемента на этом индексе. Исходный массив менять нельзя.

Имя функции: removeAtCopy.

Примеры:

- ['а', 'б', 'в'], 1: ['а', 'в']
- [7], 0: []
