# Массивы: что выбрать

Массив — упорядоченный объект. Индекс начинается с 0; последний равен length - 1. Array.isArray(value) проверяет, является ли значение массивом.

| Операция | Результат | Меняет сам массив |
| --- | --- | --- |
| push(item) | Новая длина | Да |
| pop() | Последний удалённый элемент или undefined | Да |
| unshift(item) | Новая длина | Да |
| shift() | Первый удалённый элемент или undefined | Да |
| slice(start, end) | Новая часть массива; end не включён | Нет |
| splice(start, count, ...items) | Массив удалённых элементов | Да |
| includes(value) | boolean | Нет |
| indexOf(value) | Первый индекс либо -1 | Нет |
| map(callback) | Новый массив результатов | Нет |
| filter(callback) | Новый массив подходящих элементов | Нет |
| find(callback) | Первый подходящий элемент или undefined | Нет |
| forEach(callback) | undefined | Нет |
| some(callback) | Есть хотя бы одно совпадение | Нет |
| every(callback) | Подходят все элементы | Нет |
| reduce(callback, initial) | Итог накопления | Нет |
| join(separator) | Строка | Нет |
| sort(compare) | Ссылка на отсортированный исходный массив | Да |
| toSorted(compare) | Новый отсортированный массив | Нет |
| reverse() | Ссылка на исходный массив в обратном порядке | Да |

«Нет» означает, что метод сам не записывает изменения в массив. Код callback может менять и массив, и его объекты. Поверхностная копия сохраняет ссылки на вложенные объекты.

## Выбор по результату

Нужен новый элемент для каждого входного — map; часть элементов — filter; один элемент — find; факт наличия — some; условие для всех — every; общий итог — цикл с накопителем или reduce. Для побочных действий подходит forEach, но return из его callback не возвращает результат из внешней функции.

Для пустого массива map/filter дают [], find — undefined, some — false, every — true. У reduce указывайте initial: без него пустой массив вызывает TypeError.

Числа сортируют компаратором (a, b) => a - b: без него используется строковый порядок. Новый массив отличается по === даже при равных элементах.
