# Строки: поиск и преобразование

Строки неизменяемы. Любой полученный новый текст нужно сохранить в переменную или вернуть. В основных задачах предполагаются обычные буквы без emoji и составных символов: length и индексы считают кодовые единицы UTF-16.

| Операция | Результат и границы |
| --- | --- |
| text.length | Длина |
| text[index] | Кодовая единица как строка либо undefined вне границ |
| trim() | Новый текст без крайних пробельных символов |
| toLowerCase() / toUpperCase() | Новый текст с другим регистром |
| includes(query) | boolean; поиск чувствителен к регистру |
| indexOf(query) | Первый индекс либо -1 |
| startsWith(prefix) / endsWith(suffix) | boolean: начало / конец |
| slice(start, end) | Фрагмент, end не включён; отрицательные границы от конца |
| split(separator) | Массив фрагментов |
| replace(search, replacement) | При строковом search заменяет первое совпадение |
| replaceAll(search, replacement) | При строковом search заменяет все совпадения |

Чтобы собрать строку из списка, нужен метод массива join(separator). Чтобы изменить регистр одного символа, соедините неизменённые части и преобразованный символ или используйте накопитель.

## Что проверить

- Пустой ввод до text[0].toUpperCase(): у undefined нет такого метода.
- indexOf вернул 0? Фрагмент найден: проверяйте индекс !== -1.
- Повторяющиеся пробелы после split(" ") дают пустые элементы.
- includes("") возвращает true. Если пустой запрос запрещён, проверьте его отдельно.
- Number("") даёт 0, parseFloat("4kg") даёт 4, Number("4kg") даёт NaN. Выбор зависит от контракта.

Для фрагмента с индексами от a до b включительно используйте slice(a, b + 1). Для центральных позиций сначала вычислите индекс по длине и проверьте чётность.
