# Частые вопросы

## Что нужно установить для занятий?

Ничего: достаточно браузера и JavaScript-песочницы, например [TryCode](https://trycode.pw/). Копируйте примеры и заготовки с GitHub в редактор песочницы. Проверяйте решения через `console.log`, а функции обязательно вызывайте. Node.js и npm используются преподавателем для проверки репозитория.

## Почему const не замораживает объект?

const запрещает присвоить переменной другое значение. Изменять поля объекта или элементы массива можно. Для независимых данных создают копию нужных уровней.

## Почему одинаковые объекты не равны?

=== проверяет, один ли это объект. Два отдельно созданных объекта различаются. Сравнение содержимого — отдельный алгоритм; простого универсального сравнения через === нет.

## Чем = отличается от == и ===?

= выполняет присваивание. == сравнивает с преобразованием типов. === сравнивает без такого преобразования: например, число и строка с одинаковой записью не равны. В учебных решениях обычно выбирайте ===.

## Почему && и || вернули строку?

Они выбирают операнд, а не обязательно boolean. && возвращает первый falsy или последний операнд; || — первый truthy или последний. Для boolean используйте Boolean(value) или !!value.

## Почему typeof NaN равен "number"?

NaN — специальное числовое значение. typeof не подтверждает пригодность числа для расчёта. Number.isFinite исключает NaN и бесконечности без преобразования строк.

## Почему console.log не заменяет return?

console.log показывает значение и возвращает undefined. return передаёт результат вызывающему коду и завершает текущую функцию.

## Почему map вернул массив undefined?

Callback с телом в фигурных скобках должен вернуть значение явно. У краткой стрелки без фигурных скобок возвращается результат выражения.

## Почему новая копия всё ещё меняет старый объект?

slice и Object.assign копируют один уровень. Вложенные объекты остаются общими. Копируйте отдельно те уровни, которые собираетесь менять.
