# Словарь

| Термин | Значение |
| --- | --- |
| declaration — объявление | Введение имени переменной или функции |
| initialization — инициализация | Первое задание значения переменной |
| assignment — присваивание | Запись значения через = |
| reassignment — переназначение | Новое присваивание уже существующей переменной |
| expression — выражение | Запись, вычисляющая значение |
| statement — инструкция | Отдельное действие программы |
| primitive — примитив | Значение одного из семи необъектных типов |
| object — объект | Значение, содержащее свойства; массивы и функции также объекты |
| scope — область видимости | Где доступно имя |
| hoisting — поднятие | Обработка объявлений до пошагового исполнения; детали различаются у var и let/const |
| TDZ — временная мёртвая зона | Участок, где let/const уже существуют, но ещё не инициализированы |
| parameter — параметр | Имя для входного значения в объявлении функции |
| argument — аргумент | Значение, переданное при вызове |
| return value — возвращаемое значение | Результат вызова, переданный через return |
| callback — обратный вызов | Функция, переданная другому коду для вызова |
| iteration — итерация | Один проход тела цикла |
| index — индекс | Номер позиции, обычно начиная с 0 |
| accumulator — накопитель | Состояние промежуточного результата |
| reference — ссылка | Возможность обращаться к одному и тому же объекту через разные переменные |
| mutation — изменение | Изменение существующего массива или объекта |
| shallow copy — поверхностная копия | Новый внешний объект с общими вложенными ссылками |
| truthy / falsy | Значение, дающее true / false при логическом преобразовании |
| short-circuit — короткое замыкание | Прекращение вычисления логического выражения после выбора результата |
| contract — контракт | Согласованные вход, результат и ограничения функции |
| edge case — граничный случай | Вход на границе условия, пустой ввод или другой важный край |
| debugging — отладка | Поиск причины неверного поведения |
