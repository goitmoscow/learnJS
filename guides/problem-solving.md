# Как решать задачу

## До написания кода

Опишите вход: типы, ограничения, допустимость пустого значения и необходимость сохранить исходные данные. Назовите тип результата: число, boolean, строка, элемент или список.

Разберите маленький пример вручную. Если текст и пример противоречат друг другу, запишите противоречие и задайте конкретный вопрос. Не подгоняйте алгоритм молча под один пример.

Выберите операции: условие для выбора, цикл для повторения, накопитель для итога. Начальное значение зависит от смысла: сумма — 0, произведение — 1, текст — "", список — []. Для максимума или минимума непустого списка удобно взять первый элемент.

## Во время решения

Дайте переменным имена по смыслу. Сохраняйте промежуточные результаты. На бумаге или в консоли составьте таблицу: шаг, текущий элемент, состояние до, состояние после.

Если на каждом шаге нужно помнить два предыдущих значения, сохраните новое значение до сдвига старых. Если требуется полный итог, return ставьте после цикла; при поиске первого совпадения ранний return может быть правильным.

## После решения

Проверьте:

- обычный ввод с заранее посчитанным ответом;
- пустой ввод и один элемент;
- обе стороны границы и саму границу;
- отсутствие совпадения, повторения и отрицательные числа, если они разрешены;
- неизменность входа, если это часть контракта;
- ошибочный тип и отсутствие аргумента, если задача требует проверки данных.

Для каждой проверки запишите причину: какую возможную ошибку она обнаружит. Затем объясните алгоритм без чтения кода и только после этого сокращайте запись.
