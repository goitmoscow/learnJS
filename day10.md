## 5. Цифры числа и цифры строки

Для безопасного целого числа Number.isSafeInteger проверяет и целочисленность, и диапазон точного представления. Math.abs убирает знак; String превращает модуль числа в десятичный текст в этом диапазоне. Теперь можно применять знакомые length, цикл по индексам и Number к отдельной цифре. У нуля одна цифра; знак и десятичную точку не следует считать цифрами.

Арифметический путь для неотрицательного целого: остаток % 10 получает последнюю цифру, Math.trunc(value / 10) убирает её. В цикле обновляйте value и накапливайте нужный результат. Ноль обработайте отдельно, если цикл начинается с условия value > 0. Дроби, Infinity, NaN и отсутствие аргумента проверьте до цикла.

```javascript
const reading = -608;
console.log(Number.isSafeInteger(reading));
const digits = String(Math.abs(reading));
console.log(digits);
console.log(digits.length);
console.log(Number(digits[1]));
let rest = Math.abs(reading);
while (rest > 0) {
  console.log(rest % 10);
  rest = Math.trunc(rest / 10);
}
```

Ожидаемый вывод:

```text
true
608
3
0
8
0
6
```

## Самостоятельная практика

Назовите вход, выход и алгоритм. Напишите код и проверьте примеры. В день 1 используйте выражения, со дня 2 оформляйте решения как функции.

### Задача 1. Сумма цифр строки

Дана строка, содержащая только цифры 0–9. Верните сумму цифр. Для пустой строки верните 0.

Имя функции: sumDigits.

Примеры:

- '204': 6
- '': 0
- '000': 0

### Задача 2. Названия доступных товаров

Дан массив объектов name и quantity. Верните имена товаров с quantity > 0. Сохраните порядок и входные данные.

Имя функции: inStockNames.

Примеры:

- [{name: 'Чай', quantity: 2}, {name: 'Кофе', quantity: 0}]: ['Чай']
- []: []

### Задача 3. Самое длинное слово

Во входной строке слова разделены обычными пробелами, знаков препинания и emoji нет. Верните самое длинное слово; при равенстве первое. Для пустого ввода верните пустую строку.

Имя функции: longestWord.

Примеры:

- 'кот собака лев': 'собака'
- 'дом кот': 'дом'
- '': ''

### Задача 4. Дополнительно: общие числа

Верните уникальные конечные числа, которые есть в обоих массивах. Порядок соответствует первому появлению в первом массиве.

Имя функции: commonNumbers.

Примеры:

- [3, 1, 3, 2], [2, 3]: [3, 2]
- [], [1]: []
