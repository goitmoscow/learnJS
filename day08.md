## Результат занятия

- Объяснить решение до написания кода
- Выбрать накопитель и условие

Что уже нужно знать: Материал дней 1–7. Сегодня применяем знакомые конструкции к делителям, нескольким строкам результата и последовательностям.

## Разминка

Без запуска объясните, как найти количество чётных чисел в массиве. Какие значения возьмёте для проверки?

## 1. Вход и выход

До написания кода уточните типы входных данных и результат. Разберите один обычный и один граничный пример.

Задача «найти число» и задача «вернуть список» требуют разной формы результата.

```javascript
function countPositive(numbers) {
  let count = 0;
  for (const n of numbers) {
    if (n > 0) count += 1;
  }
  return count;
}
console.log(countPositive([]));
```

Ожидаемый вывод:

```text
0
```

## 2. Состояние алгоритма

Для суммы нужен числовой накопитель, для списка массив, для построения текста строка.

Назовите начальное значение и объясните его выбор. Для произведения начальный накопитель обычно 1.

```javascript
const numbers = [2, 3, 4];
let product = 1;
for (const n of numbers) {
  product *= n;
}
console.log(product);
```

Ожидаемый вывод:

```text
24
```

## 3. Проверка решения

Проверьте обычный вход, пустой вход, один элемент и значения на границе.

Для задач на новый массив дополнительно убедитесь, что исходные данные не изменились.

```javascript
const input = [1, 2];
const output = input.map((n) => n + 1);
console.log(input.join(","));
console.log(output.join(","));
console.log(input === output);
```

Ожидаемый вывод:

```text
1,2
2,3
false
```

## 4. Поиск причины ошибки

Сравните ожидаемый результат с фактическим. Найдите первый шаг, где состояние стало неверным.

Выведите счётчик и накопитель, исправьте одну причину, затем снова проверьте примеры.

```javascript
const numbers = [2, 4];
let sum = 0;
for (let i = 0; i < numbers.length; i += 1) {
  sum += numbers[i];
  console.log(i, sum);
}
```

Ожидаемый вывод:

```text
0 2
1 6
```

## 5. Делители и границы перебора

Для положительного целого n делитель d удовлетворяет n % d === 0. Перебор кандидатов от 1 до n даёт все делители. У простого числа ровно два положительных делителя: 1 и само число. Числа меньше 2 простыми не являются; у составного числа есть делитель между 2 и n - 1.

Для проверки наличия делителя можно закончить поиск при первом совпадении через return или break. break завершает цикл, continue пропускает остаток текущей итерации. Начните с полного перебора; сокращать поиск до квадратного корня можно после проверки решения.

```javascript
const number = 14;
const divisors = [];
for (let candidate = 1; candidate <= number; candidate += 1) {
  if (number % candidate === 0) divisors.push(candidate);
}
console.log(divisors.join(","));
console.log(divisors.length);
```

Ожидаемый вывод:

```text
1,2,7,14
4
```

## 6. Несколько строк результата

Отдельно управляйте числом строк и содержимым каждой строки. Строковый накопитель можно переносить между итерациями, а можно создавать заново для каждой строки — результат будет разным. Для сетки удобны два цикла: внешний выбирает строку, внутренний наполняет её.

Разделители ставьте между элементами: добавлять разделитель перед каждым элементом, кроме первого, проще, чем удалять лишний в конце. Другой вариант — собрать массив и вызвать join.

```javascript
for (let row = 0; row < 2; row += 1) {
  let line = "";
  for (let column = 0; column < 3; column += 1) {
    if (column > 0) line += " | ";
    line += row + column;
  }
  console.log(line);
}
```

Ожидаемый вывод:

```text
0 | 1 | 2
1 | 2 | 3
```

## 7. Два предыдущих состояния

Иногда следующему шагу нужны два предыдущих значения. До обновления сохраните next, затем сдвиньте previous и current. Если сначала затереть previous, формула может начать использовать уже изменённое значение.

Для последовательности Фибоначчи каждый следующий член — сумма двух предыдущих. Начальные значения задаются отдельно. Индексы 0 и 1 обозначают два начальных члена; количество выполненных переходов и индекс результата не всегда совпадают. До цикла выпишите таблицу 0, 1, 2 и договоритесь о нулевом шаге. Отрицательное количество шагов не имеет смысла: согласуйте результат ошибки.

```javascript
let previous = 2;
let current = 5;
console.log(0, previous);
console.log(1, current);
for (let index = 2; index <= 4; index += 1) {
  const next = previous + current;
  previous = current;
  current = next;
  console.log(index, current);
}
```

Ожидаемый вывод:

```text
0 2
1 5
2 7
3 12
4 19
```

## 8. Выбор наименьшего значения

Для непустого массива инициализируйте минимум первым элементом, затем сравнивайте остальные. Так решение работает и с отрицательными числами. Для фиксированного набора аргументов действует тот же приём: начните с первого, затем независимо проверьте каждый оставшийся.

Не используйте else if для обновления минимума: после уменьшения результата следующий кандидат всё равно нужно проверить. Пустой вход требует отдельного договорённого результата.

```javascript
const temperatures = [7, -6, 3, -9];
let lowest = temperatures[0];
for (let i = 1; i < temperatures.length; i += 1) {
  if (temperatures[i] < lowest) lowest = temperatures[i];
}
console.log(lowest);
```

Ожидаемый вывод:

```text
-9
```

## Самостоятельная практика

Назовите вход, выход и алгоритм. Напишите код и проверьте примеры. В день 1 используйте выражения, со дня 2 оформляйте решения как функции.

### Задача 1. Сумма чётных

Верните сумму чётных целых чисел массива. Для пустого массива верните 0. Сначала решите циклом.

Имя функции: sumEven.

Примеры:

- [1, 2, 4, 5]: 6
- [-2, 0, 3]: -2

### Задача 2. Гласные в тексте

Посчитайте английские гласные a, e, i, o, u без учёта регистра. Остальные символы не учитываются.

Имя функции: countVowels.

Примеры:

- 'Hello': 2
- 'AEIOU': 5
- '': 0

### Задача 3. Максимум в массиве

Верните максимальное число. Для пустого массива верните undefined. Массив менять нельзя.

Имя функции: maxNumber.

Примеры:

- [-5, -2, -9]: -2
- []: undefined

### Задача 4. Убрать повторы

Верните новый массив уникальных конечных чисел, сохранив порядок первого появления. Решите без Set.

Имя функции: uniqueNumbers.

Примеры:

- [2, 1, 2, 3, 1]: [2, 1, 3]
- []: []

### ★ 1. Поймать первый неверный шаг

Скопируйте свой подсчёт положительных чисел. В отдельной учебной копии намеренно замените numbers[i] > 0 на numbers[i] >= 0. Найдите вход, на котором ответы различаются. Через точку остановки покажите значения i, элемента и счётчика до и после ошибочного шага; затем исправьте код.

Что исследовать: Найдите, как поставить breakpoint, сделать один шаг и посмотреть локальные переменные. Приложите текстовую таблицу наблюдений; скриншот не обязателен.

Статьи: [Отладка в браузере](https://learn.javascript.ru/debugging-chrome).

### ★ 2. Проверки раньше кода

Для функции clampScore(value, min, max) составьте не менее шести проверок до реализации. Все аргументы — конечные числа, min <= max. Верните ближайшую границу при выходе за диапазон, иначе value. Примеры: (12, 0, 10) → 10; (-2, 0, 10) → 0. Добавьте равные границы, отрицательный диапазон и точное попадание на границу.

Что исследовать: Прочитайте, зачем нужны ожидаемые результаты и независимые проверки. Достаточно таблицы и простого запуска своих примеров: устанавливать Mocha не нужно.
