# День 3. Циклы и накопление результата

## Результат занятия

- Проследить выполнение цикла по шагам
- Накопить сумму и количество
- Пройти строку или массив по индексам

Что уже нужно знать: Условия, функции, параметры и return.

## Разминка

Что вернёт функция с return внутри первой подходящей ветки? Где хранится её локальная переменная?

## 1. Цикл for

for повторяет действия. В заголовке задаём начало, условие продолжения и изменение счётчика.

Условие проверяется перед каждой итерацией. Когда оно ложно, цикл заканчивается.

```javascript
for (let i = 0; i < 3; i += 1) {
  console.log(i);
}
```

Ожидаемый вывод:

```text
0
1
2
```

## 2. Накопитель

Результат, который нужен после цикла, объявляют до цикла.

На каждом шаге обновляем накопитель. Возвращаем итог после окончания повторений.

```javascript
function sumTo(n) {
  let sum = 0;
  for (let i = 1; i <= n; i += 1) {
    sum += i;
  }
  return sum;
}
console.log(sumTo(4));
```

Ожидаемый вывод:

```text
10
```

## 3. Строка и индекс

length даёт длину строки в кодовых единицах UTF-16. Для наших задач используем обычные буквы без emoji.

Первый индекс равен 0, последний равен length - 1. Условие i < length включает последний символ.

```javascript
const word = "кот";
console.log(word.length);
for (let i = 0; i < word.length; i += 1) {
  console.log(word[i]);
}
```

Ожидаемый вывод:

```text
3
к
о
т
```

## 4. Массив как список

Массив хранит упорядоченные значения. Элемент читают по индексу, количество элементов получают через length.

Тот же цикл подходит для списка чисел. Более подробно массивы разберём завтра.

```javascript
const scores = [10, 20, 30];
let sum = 0;
for (let i = 0; i < scores.length; i += 1) {
  sum += scores[i];
}
console.log(sum);
```

Ожидаемый вывод:

```text
60
```

## 5. Цикл while

while повторяет блок, пока условие истинно. Изменение состояния записываем внутри блока.

Проверьте, что выполнение когда-нибудь сделает условие ложным.

```javascript
let left = 3;
while (left > 0) {
  console.log(left);
  left -= 1;
}
```

Ожидаемый вывод:

```text
3
2
1
```

## 6. Условие внутри цикла

if внутри цикла позволяет учитывать только нужные значения.

return внутри цикла завершит всю функцию, поэтому для накопления итога return ставим после цикла.

```javascript
const numbers = [2, -1, 0, 4];
let count = 0;
for (let i = 0; i < numbers.length; i += 1) {
  if (numbers[i] > 0) count += 1;
}
console.log(count);
```

Ожидаемый вывод:

```text
2
```

## 7. Направление и шаг цикла

Счётчик может уменьшаться, а шаг может быть любым. Проверьте начальное значение, включение границы и направление изменения. Действие после цикла выполняется один раз; текст можно передать аргументом функции.

Чтобы заменить while на for, перенесите начальное состояние в первую часть заголовка, условие во вторую, изменение счётчика в третью. Сохраните порядок действий. Если в теле есть continue, отдельно проверьте, где теперь выполняется шаг.

```javascript
function showCheckpoints(note) {
  for (let point = 18; point >= 6; point -= 6) {
    console.log(point);
  }
  console.log(note);
}
showCheckpoints("Проверка закончена");
```

Ожидаемый вывод:

```text
18
12
6
Проверка закончена
```

## 8. Накопление строки и остаток

Строковый накопитель начинается с "". На каждом шаге добавляйте символ или фрагмент. Для изменения отдельных позиций выбирайте действие по индексу: i % period помогает повторять правило. Индекс 0 соответствует первой позиции при чтении человеком; договоритесь, с какой нумерацией работает условие.

В примере toUpperCase() возвращает символ в верхнем регистре, не меняя исходную строку; подробно методы строк разберём в день 7.

Для выбора чисел по делимости используйте value % divisor === 0. Если несколько условий пересекаются, сначала обработайте их пересечение через &&, затем отдельные случаи в else if. Так наиболее общий случай не перехватит более специальный.

```javascript
const word = "abcdef";
let result = "";
for (let i = 0; i < word.length; i += 1) {
  if (i % 3 === 2) {
    result += word[i].toUpperCase();
  } else {
    result += word[i];
  }
}
console.log(result);
```

Ожидаемый вывод:

```text
abCdeF
```

## Самостоятельная практика

Назовите вход, выход и алгоритм. Напишите код и проверьте примеры. В день 1 используйте выражения, со дня 2 оформляйте решения как функции.

### Задача 1. Сумма от 1 до n

Для целого n >= 0 верните сумму чисел от 1 до n. Решите циклом.

Имя функции: sumTo.

Примеры:

- 4: 10
- 0: 0

### Задача 2. Количество символов

Верните, сколько раз char встречается в text. Сравнение чувствительно к регистру. text содержит обычные буквы без emoji.

Имя функции: countChar.

Примеры:

- 'мама', 'м': 2
- '', 'а': 0

### Задача 3. Сумма положительных

Верните сумму элементов массива numbers, которые строго больше нуля. Для пустого массива верните 0.

Имя функции: sumPositive.

Примеры:

- [2, -1, 0, 4]: 6
- []: 0

### Задача 4. Строка наоборот

Верните символы строки в обратном порядке. Используйте цикл. Вход содержит обычные буквы без emoji.

Имя функции: reverseText.

Примеры:

- 'кот': 'ток'
- '': ''

### ★ 1. Датчик с сигналом остановки

Напишите sumBeforeStop(readings). Складывайте положительные показания до первого отрицательного; нули пропускайте, отрицательное и последующие значения не учитывайте. [4, 0, 7, -1, 50] → 11; [0, -2, 8] → 0; [] → 0. Исходный массив не меняйте.

Что исследовать: Найдите различия break, continue и return. В решении используйте обычный for, break и continue; объясните, почему return внутри каждой итерации здесь мешает.

Напишите daysToReach(start, target): каждый день величина удваивается, нужно вернуть минимальное число дней до достижения target. Вход — конечные числа: start > 0, target >= 0. (3, 20) → 3; (8, 8) → 0; (8, 0) → 0. Решите через while и составьте таблицу изменения величины.

Что исследовать: Найдите условие выполнения while. Объясните, зачем в контракте start > 0 и что произойдёт при нуле, если target положителен.

Статьи: [Циклы: условие продолжения](https://learn.javascript.ru/while-for).
