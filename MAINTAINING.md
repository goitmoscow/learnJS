# Как править материалы

Редактируйте уроки day01.md–day10.md напрямую. Примеры находятся в examples, заготовки задач в practice, решения преподавателя в solutions.

При изменении примера обновите его в уроке и в соответствующем JavaScript-файле. При изменении условий задачи проверьте решение и ожидаемые результаты в tests.

## Локальная проверка для преподавателя

Ученики работают в браузерной [песочнице](https://trycode.pw/); установка окружения не входит в программу. Команды ниже нужны только при редактировании и проверке материалов.

Для локального запуска нужен Node.js 20 или новее. Устанавливать зависимости не требуется. Например, из корня репозитория:

```bash
node examples/day01.js
```

Проверка всех примеров и эталонных решений:

```bash
npm test
```

`npm test` проверяет решения преподавателя и вывод примеров. Незавершённые заготовки ученика в эту проверку не входят. Файлы `solutions/*.cjs` используют CommonJS для автоматической проверки; для показа в песочнице копируйте только нужную функцию и вызовы, без `module.exports` и `require`.

План занятий находится в PLAN.md, рекомендации преподавателю — в teacher/README.md.

Короткие справочники находятся в guides. В каждом дне сохраняйте две задачи ★; условия в уроке и practice должны совпадать. Ссылки на внешние статьи дополняют объяснения, но не заменяют обязательные темы.
