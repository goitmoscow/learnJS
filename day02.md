# День 2. Условия и простые функции

## Результат занятия

- Выбрать ветку if/else
- Объединить условия через && и ||
- Описать функцию с параметрами и return

Что уже нужно знать: Переменные, сравнения, арифметика, console.log.

## Разминка

Предскажите результаты: 18 >= 18, '18' === 18, 0 === false.

## 1. Условие if

if выполняет блок, когда условие истинноподобно. else задаёт альтернативу.

Сначала сформулируйте проверку словами, затем запишите сравнение.

```javascript
const age = 17;
if (age >= 18) {
  console.log("Доступ открыт");
} else {
  console.log("Нужен взрослый");
}
```

Ожидаемый вывод:

```text
Нужен взрослый
```

## 2. Несколько веток

else if позволяет проверить следующее условие. Выполняется первая подходящая ветка.

Порядок проверок важен, особенно если диапазоны пересекаются.

```javascript
const score = 82;
if (score >= 90) {
  console.log("Отлично");
} else if (score >= 60) {
  console.log("Зачёт");
} else {
  console.log("Повторить");
}
```

Ожидаемый вывод:

```text
Зачёт
```

## 3. Логические операторы

&& удобно читать как «и», || как «или». ! превращает значение в boolean и отрицает его.

Вычисление идёт слева направо. && останавливается на первом falsy и возвращает его; если falsy нет, возвращает последний операнд. || останавливается на первом truthy и возвращает его; если truthy нет, возвращает последний операнд. Оставшаяся часть выражения после остановки не вычисляется: это короткое замыкание.

Поэтому результат может быть числом, строкой, null или undefined. && имеет более высокий приоритет, чем ||; сложные условия лучше группировать скобками.

```javascript
const age = 20;
const hasTicket = true;
console.log(age >= 18 && hasTicket);
console.log(false || "Гость");
console.log(!true);
```

Ожидаемый вывод:

```text
true
Гость
false
```

## 4. Truthy и falsy

В условиях false, 0, -0, 0n, пустая строка, null, undefined и NaN трактуются как ложь.

Непустая строка '0' истинноподобна. Пустые массив и объект тоже истинноподобны.

```javascript
console.log(Boolean(""));
console.log(Boolean("0"));
console.log(Boolean(0));
console.log(Boolean([]));
```

Ожидаемый вывод:

```text
false
true
false
true
```

## 5. Параметры и вызов

Функция объединяет шаги решения под именем. Параметр получает значение аргумента при вызове.

return возвращает результат вызывающему коду и завершает текущий вызов.

```javascript
function double(number) {
  return number * 2;
}
const result = double(7);
console.log(result);
console.log(double(0));
```

Ожидаемый вывод:

```text
14
0
```

## 6. return и console.log

console.log показывает значение, но не заменяет возвращаемый результат функции.

Если return не сработал, вызов функции возвращает undefined. Переменная внутри функции доступна только в своей области видимости.

```javascript
function add(a, b) {
  return a + b;
}
const total = add(2, 3);
console.log(total + 10);
```

Ожидаемый вывод:

```text
15
```

## 7. Операнды и двойное отрицание

! сначала преобразует значение в boolean, затем меняет его на противоположное. Запись !!value — два последовательных применения !, а не отдельный оператор. Итог совпадает с Boolean(value).

Значение по умолчанию через || заменяет и допустимый 0, и пустую строку. Не используйте такую замену, если эти значения нужно сохранить.

```javascript
console.log("черновик" && 0 && "готово");
console.log("черновик" && "готово");
console.log("" || "без названия" || "резерв");
console.log(false || null);
console.log(!!"запись");
console.log(!!0);
```

Ожидаемый вывод:

```text
0
готово
без названия
null
true
false
```

## 8. Блок, функция и объявления

let и const видны внутри своего блока { } и вложенных блоков. Локальные переменные функции недоступны снаружи. var имеет область функции (или область верхнего уровня), а обычный блок if не создаёт для него отдельную область.

Объявление var обрабатывается до выполнения инструкций: чтение до строки объявления даёт undefined, присваивание происходит на своей строке. Это называют поднятием, или hoisting. Связывания let/const тоже создаются заранее, но до объявления не инициализированы: обращение к ним вызывает ReferenceError. Этот участок называют временной мёртвой зоной (TDZ). Пишите объявления до использования.

```javascript
function showScope() {
  console.log(status);
  if (true) {
    var status = "в процессе";
    const label = "внутри блока";
    console.log(label);
  }
  console.log(status);
  // label здесь недоступна
}
showScope();
```

Ожидаемый вывод:

```text
undefined
внутри блока
в процессе
```

## 9. Проверка аргумента до вычислений

Если аргумент не передан, соответствующий параметр получает undefined. Проверяйте вход перед арифметикой: typeof value === "number" не исключает NaN и Infinity. Number.isFinite(value) принимает только конечные числа без преобразования строк.

Сначала согласуйте контракт: например, здесь ошибочный ввод даёт undefined. В другой задаче может требоваться строка или другой результат — следуйте условию, а не универсальному шаблону.

```javascript
function hoursToMinutes(hours) {
  if (!Number.isFinite(hours)) return undefined;
  return hours * 60;
}
console.log(hoursToMinutes(1.5));
console.log(hoursToMinutes("1.5"));
console.log(hoursToMinutes());
console.log(hoursToMinutes(NaN));
```

Ожидаемый вывод:

```text
90
undefined
undefined
undefined
```
