## Как заниматься

Для занятий достаточно браузера и JavaScript-песочницы, например [TryCode](https://trycode.pw/). Устанавливать Node.js, редактор, npm или другие программы не нужно.

1. Выполните разминку.
2. Откройте песочницу, выберите JavaScript и скопируйте один пример из урока или файла `examples/dayNN.js`. Запустите код и сравните вывод с ожидаемым.
3. Скопируйте заготовку из `practice/dayNN.js` в песочницу, решите задачу и проверьте её на примерах из урока. Файлы можно открыть прямо на GitHub; скачивать репозиторий не требуется.
4. Повторите решение без подсказки и добавьте граничные проверки.
5. Выполните две задачи ★ по теме дня: найдите информацию, примените её и объясните результат. [Порядок самостоятельного поиска](guides/self-study.md).

Всего: 40 базовых задач и 20 дополнительных задач ★. Для каждой задачи ★ есть статья и требования к самостоятельной проверке.

В первый день выводите результат выражения через `console.log`. Начиная со второго дня, после своей функции добавляйте вызовы с разными аргументами. Например, после решения задачи `canEnter`:

```javascript
console.log(canEnter(17)); // ожидаем false
console.log(canEnter(18)); // ожидаем true
console.log(canEnter(25)); // ожидаем true
```

Одно объявление функции ничего не выводит: для проверки её нужно вызвать. Для следующего примера заменяйте код в редакторе песочницы. Если при повторном запуске появляется ошибка повторного объявления переменной, перезапустите среду выполнения песочницы или обновите страницу, предварительно сохранив своё решение.
