## Как заниматься

Выберите удобный способ запуска. Все уроки и задачи доступны в обоих вариантах.

| Вариант | Как заниматься |
| --- | --- |
| Окружение уже настроено | Откройте свои файлы в VS Code и запускайте их через Node.js в терминале, например `node day01.js` |
| Окружение ещё не настроено | Откройте JavaScript-песочницу, например [TryCode](https://trycode.pw/), и скопируйте код туда. Устанавливать программы не обязательно |

[Инструкция по установке VS Code, Node.js через nvm и настройке расширений](guides/environment.md) — если хотите подготовить локальное окружение. Можно начать с песочницы и перейти к файлам позже.

1. Выполните разминку.
2. Запустите один пример из урока или файла `examples/dayNN.js`: в песочнице либо локально. Сравните вывод с ожидаемым.
3. Возьмите заготовку из `practice/dayNN.js`, решите задачу и проверьте её на примерах из урока. В песочнице скопируйте код с GitHub; локально сохраните заготовку в свой файл `.js`.
4. Повторите решение без подсказки и добавьте граничные проверки.
5. Выполните две задачи ★ по теме дня: найдите информацию, примените её и объясните результат. [Порядок самостоятельного поиска](guides/self-study.md).

Всего: 40 базовых задач и 20 дополнительных задач ★. Для каждой задачи ★ есть статья и требования к самостоятельной проверке.

В первый день выводите результат выражения через `console.log`. Начиная со второго дня, после своей функции добавляйте вызовы с разными аргументами. Например, после решения задачи `canEnter`:

```javascript
console.log(canEnter(17)); // ожидаем false
console.log(canEnter(18)); // ожидаем true
console.log(canEnter(25)); // ожидаем true
```

Одно объявление функции ничего не выводит: для проверки её нужно вызвать. Локально сохраняйте файл перед каждым запуском. В песочнице для следующего примера заменяйте код; при ошибке повторного объявления переменной сохраните решение и перезапустите среду выполнения или обновите страницу.

Если открыли весь репозиторий в VS Code, готовые примеры запускаются из его корня:

```bash
node examples/day01.js
```

Для учебных примеров и задач установка npm-пакетов не требуется.
