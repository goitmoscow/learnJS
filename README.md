## Как заниматься

1. Выполните разминку.
2. Запускайте примеры по одному в консоли браузера или JavaScript-песочнице.
3. Решите задачи и проверьте примеры.
4. Повторите решение без подсказки и добавьте граничные проверки.
5. Выполните две задачи ★ по теме дня: найдите информацию, примените её и объясните результат. [Порядок самостоятельного поиска](guides/self-study.md).

Всего: 40 базовых задач и 20 дополнительных задач ★. Для каждой задачи ★ есть статья и требования к самостоятельной проверке.

Для локального запуска подходит Node.js 20 или новее:

```bash
node examples/day01.js
node practice/day02.js
npm test
```

npm test проверяет решения преподавателя и вывод примеров. Незавершённые заготовки ученика не входят в этот запуск. Зависимости для проверок устанавливать не требуется.
