# План курса

Дни 1–7: новая тема, короткий пример, самостоятельная попытка и разбор. Дни 8–10: практика алгоритмических приёмов, работа с данными и учебное пробное интервью. Это план обучения, а не описание действующих условий поступления.

| День | Тема | Результат |
| --- | --- | --- |
| 1 | [Переменные, типы и операторы](day01.md) | Выполнить расчёт и явное преобразование типов |
| 2 | [Условия и простые функции](day02.md) | Описать функцию с параметрами и return |
| 3 | [Циклы и накопление результата](day03.md) | Пройти строку или массив по индексам |
| 4 | [Массивы, изменение и копирование](day04.md) | Отличить исходный массив от копии |
| 5 | [Callback и методы массивов](day05.md) | Выбрать метод по типу результата |
| 6 | [Объекты и массивы объектов](day06.md) | Отобрать объекты из массива по условию |
| 7 | [Строки и комбинированные задачи](day07.md) | Построить решение из нескольких понятных шагов |
| 8 | [Практика: алгоритм и граничные случаи](day08.md) | Проверить границы, делители и обновление состояния |
| 9 | [Практика: строки и данные об объектах](day09.md) | Обработать массив объектов без лишних изменений |
| 10 | [Пробное интервью и итоги](day10.md) | Составить личный план повторения |

Дополнительно после уверенной базы: some/every, reduce, toSorted, тернарный оператор и switch. IIFE, устройство прототипов, классы и асинхронность в обязательную часть не входят. В каждом дне есть две дополнительные задачи ★ со статьями. Их цель — тренировать самостоятельный поиск; обязательные объяснения находятся в основных разделах уроков.
