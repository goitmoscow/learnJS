# День 7. Строки и комбинированные задачи

## Результат занятия

- Выбрать строковый метод под задачу
- Разделить строку на части и собрать обратно
- Построить решение из нескольких понятных шагов

Что уже нужно знать: Строковые индексы, функции и методы массивов.

## Разминка

Чем отличается строка '123' от массива [1, 2, 3]? Можно ли изменить символ строки присваиванием по индексу?

## 1. Строки неизменяемы

Методы строк возвращают результат, сохраняя исходную строку. Сохраните новое значение, если оно нужно дальше.

Индексы и length для обычных букв знакомы по циклам. Emoji и составные символы требуют отдельной обработки.

```javascript
const name = "Анна";
const upper = name.toUpperCase();
console.log(upper);
console.log(name);
```

Ожидаемый вывод:

```text
АННА
Анна
```

## 2. Пробелы и регистр

trim удаляет пробельные символы по краям. Внутренние пробелы он сохраняет.

toLowerCase и toUpperCase помогают привести текст к одному регистру перед сравнением.

```javascript
const input = "  JavaScript  ";
const normalized = input.trim().toLowerCase();
console.log(normalized);
console.log(input.length);
```

Ожидаемый вывод:

```text
javascript
14
```

## 3. Поиск и фрагмент

includes возвращает boolean. Поиск чувствителен к регистру, поэтому при необходимости нормализуйте обе строки.

slice возвращает часть строки: начальная граница включается, конечная не включается.

```javascript
const text = "JavaScript";
console.log(text.includes("Script"));
console.log(text.includes("script"));
console.log(text.slice(0, 4));
```

Ожидаемый вывод:

```text
true
false
Java
```

## 4. split: строка в массив

split разделяет строку по указанному разделителю. Результат всегда массив строк.

Для пустого ввода или нескольких пробелов могут появиться пустые элементы. Проверьте их явно.

```javascript
const input = "  Анна  Олег ";
const parts = input.trim().split(" ");
const words = parts.filter((part) => part !== "");
console.log(words.length);
console.log(words[1]);
```

Ожидаемый вывод:

```text
2
Олег
```

## 5. join: массив в строку

join соединяет элементы массива строкой-разделителем. Результат имеет тип string.

Удобно разделить преобразование текста на три этапа: разбить, изменить части, собрать.

```javascript
const names = ["Анна", "Олег"];
const line = names.join(", ");
console.log(line);
console.log(typeof line);
```

Ожидаемый вывод:

```text
Анна, Олег
string
```

## 6. Решение по шагам

Перед кодом запишите вход, выход и примеры. Затем выберите знакомые операции для каждого шага.

Сначала сохраните промежуточные результаты в переменные. Короткая цепочка методов нужна только после понимания шагов.

```javascript
function initials(fullName) {
  const words = fullName.trim().split(" ");
  const nonEmpty = words.filter((w) => w !== "");
  const letters = nonEmpty.map((w) => w[0].toUpperCase());
  return letters.join(".");
}
console.log(initials("  анна иванова "));
```

Ожидаемый вывод:

```text
А.И
```

## 7. Индекс, границы и округление

Индекс должен быть целым. Math.floor(x) округляет вниз; Math.trunc(x) отбрасывает дробную часть. Для неотрицательных индексов результаты совпадают. Различайте чётность длины (length % 2) и чётность индекса (i % 2).

У нечётной длины центральный индекс Math.floor(length / 2); у чётной две центральные позиции length / 2 - 1 и length / 2. Для пустой строки нет символа: text[0] даёт undefined. Перед вызовом метода у символа проверьте длину.

slice(0, end) берёт префикс, slice(start) — остаток. Конечная граница больше длины обрезается до конца. Если количество запрошенных символов неположительно и по контракту нужен пустой результат, проверьте это до slice: отрицательная конечная граница означает отсчёт от конца. Отрицательные индексы slice отсчитывает от конца; например, slice(1, -1) убирает крайние символы. Если требуется удалить другие позиции, сначала выпишите их индексы: это другая операция.

```javascript
const caption = "планета";
const cursor = Math.floor(caption.length / 2);
console.log(cursor);
console.log(caption.slice(cursor - 1, cursor + 2));
console.log("маршрут".slice(0, 50));
console.log("план".slice(1, -1));
console.log("".slice(0, 2));
```

Ожидаемый вывод:

```text
3
ане
маршрут
ла

```

## 8. Выбрать, заменить или пропустить символ

Строку нельзя изменить по индексу. Создайте новую через срезы или накопитель. При обходе добавляйте символ, только если его позиция подходит; чтобы изменить регистр, добавляйте результат toUpperCase/toLowerCase.

Для нескольких удаляемых индексов условие должно исключать каждый из них. Проверьте, не совпадают ли они на коротком входе. indexOf возвращает первый индекс найденного фрагмента либо -1. Найденный индекс 0 нельзя проверять как boolean: сравнивайте с -1.

```javascript
const code = "robot";
const removedIndex = 2;
const withoutOne = code.slice(0, removedIndex) + code.slice(removedIndex + 1);
console.log(withoutOne);
let selected = "";
for (let i = 0; i < code.length; i += 1) {
  if (i % 3 !== 1) selected += code[i];
}
console.log(selected);
console.log(code.indexOf("ro"));
console.log(code.indexOf("x"));
```

Ожидаемый вывод:

```text
root
rbo
0
-1
```

## 9. Текстовый шаблон и числовой фрагмент

Шаблонная строка в обратных кавычках позволяет подставлять значения выражений внутрь текста. Сначала проверьте необязательный текст, потом собирайте сообщение. Параметр без аргумента равен undefined; typeof позволяет проверить его до обращения к .length.

Для числового фрагмента отделите служебный текст, проверьте непустую часть и преобразуйте её целиком через Number. parseFloat может проигнорировать хвост и потому не подходит для строгой проверки записи. Допустимый формат числа всегда задавайте отдельно: Number также понимает пробелы, знак, экспоненту и некоторые другие формы.

```javascript
const label = "Секция";
const position = 4;
console.log(`${label}: место ${position}`);
const record = "уровень:7.25";
const separator = record.indexOf(":");
const fragment = record.slice(separator + 1).trim();
console.log(Number(fragment));
console.log(Number("7.25level"));
console.log(parseFloat("7.25level"));
```

Ожидаемый вывод:

```text
Секция: место 4
7.25
NaN
7.25
```

## Самостоятельная практика

Назовите вход, выход и алгоритм. Напишите код и проверьте примеры. В день 1 используйте выражения, со дня 2 оформляйте решения как функции.

### Задача 1. Очистить имя

Удалите пробелы по краям и приведите строку к нижнему регистру.

Имя функции: normalizeName.

Примеры:

- '  АННА ': 'анна'
- '': ''

### Задача 2. Поиск без учёта регистра

Верните true, если text содержит query без учёта регистра. Пустой query считается найденным.

Имя функции: containsText.

Примеры:

- 'JavaScript', 'SCRIPT': true
- 'кот', 'пёс': false

### Задача 3. Инициалы

Получите заглавные первые буквы слов, разделённые точкой. Разделитель во входе обычный пробел, повторения и крайние пробелы разрешены. Пустой ввод даёт пустую строку.

Имя функции: getInitials.

Примеры:

- '  анна иванова ': 'А.И'
- '': ''

### Задача 4. Длинные слова

Верните массив слов с длиной не меньше minLength. Во входе обычные пробелы, слова без знаков препинания и emoji.

Имя функции: longWords.

Примеры:

- 'кот и собака', 3: ['кот', 'собака']
- '', 1: []

## Самостоятельная подготовка ★

Две дополнительные задачи на поиск и применение информации. Сначала сформулируйте свой поисковый запрос, затем используйте статьи как отправную точку. [Как искать и оформлять результат](guides/self-study.md).

### ★ 1. Метка маршрута

Напишите routeTag(text): уберите крайние пробелы, приведите к нижнему регистру и замените каждый обычный пробел на дефис. "  Север Юг  " → "север-юг"; строка из «А», двух пробелов и «Б» → "а--б"; "" → "". Сжатие повторяющихся пробелов и транслитерация не требуются.

Что исследовать: Найдите отличие replace от replaceAll. Используйте строковый образец, регулярные выражения здесь не нужны.

Статьи: [String.replaceAll](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/replaceAll).

### ★ 2. Служебный префикс

Напишите isServiceTag(text), возвращающую true, если после trim строка начинается с "sys:" без учёта регистра. " SYS:backup " → true; "user:sys:backup" → false; "" → false. Реализуйте через startsWith и сравните с includes.

Что исследовать: Найдите параметр позиции у startsWith и объясните, почему наличие фрагмента внутри строки не означает нужное начало.

Статьи: [String.startsWith](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/startsWith).
