## Разминка

Когда нужен filter, а когда find? Что вернёт find, если подходящего элемента нет?

## 1. Объект: связанные данные

Объект хранит свойства в формате ключ: значение. Так удобно объединить данные об одном человеке или товаре.

Имена ключей обычно строки. Значениями могут быть числа, строки, массивы и другие объекты.

```javascript
const user = {
  name: "Анна",
  age: 20
};
console.log(user.name);
console.log(user.age);
```

Ожидаемый вывод:

```text
Анна
20
```

## 2. Точка и квадратные скобки

Через точку обращаются по известному имени свойства. Скобки удобны, если имя хранится в переменной.

Чтение отсутствующего свойства возвращает undefined.

```javascript
const user = { name: "Анна", age: 20 };
const key = "name";
console.log(user[key]);
console.log(user.city);
```

Ожидаемый вывод:

```text
Анна
undefined
```

## 3. Изменение свойств

Свойство можно добавить, изменить или удалить. const при этом продолжает хранить ссылку на тот же объект.

Object.hasOwn проверяет собственное свойство, даже если его значение равно undefined.

```javascript
const user = { name: "Анна" };
user.city = "Москва";
user.name = "Ира";
console.log(user.name);
console.log(Object.hasOwn(user, "city"));
delete user.city;
console.log(Object.hasOwn(user, "city"));
```

Ожидаемый вывод:

```text
Ира
true
false
```

## 4. Ссылки и копирование

Присваивание объекта другой переменной копирует ссылку. Обе переменные обращаются к одному объекту.

Object.assign({}, source) делает поверхностную копию. Вложенные объекты при этом остаются общими.

```javascript
const first = { score: 1 };
const alias = first;
alias.score = 2;
console.log(first.score);
const copy = Object.assign({}, first);
copy.score = 9;
console.log(first === copy);
console.log(first.score);
```

Ожидаемый вывод:

```text
2
false
2
```

## 5. Ключи и значения

Object.keys возвращает массив собственных перечисляемых строковых ключей, Object.values массив значений.

Object.entries возвращает массив пар [ключ, значение]. Эти массивы можно обходить привычными способами.

```javascript
const scores = { Анна: 10, Олег: 20 };
console.log(Object.keys(scores).join(", "));
let sum = 0;
for (const value of Object.values(scores)) {
  sum += value;
}
console.log(sum);
```

Ожидаемый вывод:

```text
Анна, Олег
30
```

## 6. Отбор объектов

filter выбирает подходящие объекты, map получает нужное поле из каждого выбранного объекта.

Новый массив после filter содержит ссылки на исходные объекты. Для независимых объектов нужно копировать и сами элементы.

```javascript
const users = [
  { name: "Анна", age: 20 },
  { name: "Олег", age: 16 }
];
const adults = users.filter((u) => u.age >= 18);
const names = adults.map((u) => u.name);
console.log(names.join(", "));
```

Ожидаемый вывод:

```text
Анна
```

## 7. Равенство объектов

=== для объектов сравнивает идентичность, а не содержимое. Два отдельно созданных объекта различаются даже при одинаковых полях. Две переменные с одной ссылкой равны. Копия через Object.assign имеет другую идентичность, хотя её поля могут совпадать.

```javascript
const card = { title: "Заметка" };
const other = { title: "Заметка" };
const alias = card;
console.log(card === other);
console.log(card === alias);
console.log(card.title === other.title);
```

Ожидаемый вывод:

```text
false
true
true
```

Назовите вход, выход и алгоритм. Напишите код и проверьте примеры. В день 1 используйте выражения, со дня 2 оформляйте решения как функции.

### Задача 1. Значение по ключу

Верните значение свойства key из object. Если свойства нет, естественный результат undefined.

Имя функции: getField.

Примеры:

- {name: 'Анна'}, 'name': 'Анна'
- {}, 'age': undefined

### Задача 2. Имена взрослых

Дан массив объектов с полями name и age. Верните массив имён людей с age >= 18.

Имя функции: getAdultNames.

Примеры:

- [{name: 'Анна', age: 18}, {name: 'Ира', age: 17}]: ['Анна']
- []: []

### Задача 3. Сумма значений объекта

Объект содержит только числовые оценки. Верните их сумму. Для пустого объекта верните 0.

Имя функции: sumScores.

Примеры:

- {a: 10, b: 20}: 30
- {}: 0

### Задача 4. Дополнить копию объекта

Верните поверхностную копию user с полем city. Исходный объект менять нельзя.

Имя функции: withCity.

Примеры:

- {name: 'Анна'}, 'Омск': {name: 'Анна', city: 'Омск'}
- Исходный user без нового поля

## Самостоятельная подготовка ★

Две дополнительные задачи на поиск и применение информации. Сначала сформулируйте свой поисковый запрос, затем используйте статьи как отправную точку. [Как искать и оформлять результат](guides/self-study.md).

### ★ 1. Поле существует

Напишите hasSetting(settings, key), проверяющую именно собственное свойство. Для {sound: undefined}, "sound" получите true, для {}, "sound" — false. Проверьте также ключ "toString" у пустого объекта. Сравните результат с settings[key] !== undefined.

Что исследовать: Найдите Object.hasOwn и различие между отсутствующим полем и полем со значением undefined. Достаточно знать, что некоторые свойства доступны через прототип; устройство прототипов пока не требуется.

Статьи: [Object.hasOwn](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/hasOwn).

### ★ 2. Независимые настройки

Напишите withTheme(profile, theme) для данных вида {name: "Лена", settings: {theme: "light", fontSize: 16}}. Верните новый profile и новый settings с заменённой theme, сохранив остальные поля. Проверьте равенство ссылок и изменение вложенного settings у результата: исходник должен остаться прежним.

Что исследовать: Найдите разницу поверхностного копирования и копирования нужных уровней. Объясните, почему одной копии внешнего объекта недостаточно.

Статьи: [Копирование объектов и ссылки](https://learn.javascript.ru/object-copy).
